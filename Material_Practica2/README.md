# Material de apoyo — Práctica 2

Este paquete complementa el enunciado de la Práctica 2 y la definición vigente de
MiniC. No sustituye ninguno de esos documentos.

## Punto de partida

La Práctica 2 es una extensión de la Práctica 1. Cada equipo deberá trabajar sobre
su propia implementación y conservar las funcionalidades léxicas ya desarrolladas.

No reemplacen su proyecto completo con el contenido de este paquete. Copien o
integren únicamente las pruebas públicas en el directorio de pruebas de su
proyecto.

## Contenido

- `GUIA_INTEGRACION_P2.md`: orden sugerido para extender el lexer.
- `GUIA_REPORTE_P2.md`: contenido mínimo recomendado para el reporte.
- `tests/public/inputs/`: entradas de las pruebas públicas.
- `tests/public/expected/`: salidas estándar exactas esperadas.
- `tests/public/run_public_tests.sh`: ejecutor de las pruebas públicas.
- `tests/public/README.md`: descripción de los casos y forma de uso.

## Importante

- El paquete no incluye código fuente del lexer.
- El paquete no incluye `Makefile` ni `CHANGELOG.md`.
- Las pruebas públicas representan un conjunto mínimo.
- Cada equipo deberá diseñar e incluir sus propias pruebas.
- Durante la evaluación podrán utilizarse casos adicionales que verifiquen
  exclusivamente los requisitos publicados.
