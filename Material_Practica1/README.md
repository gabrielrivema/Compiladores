# Material de apoyo — Práctica 1

Este directorio contiene material complementario para desarrollar y verificar la Práctica 1. El enunciado completo se encuentra en `Compiladores_Practica1.pdf`.

## Contenido

- `base-inicial/`: proyecto incompleto pero compilable para comenzar la práctica.
- `PLANTILLA_README.md`: plantilla para el README de la entrega.
- `GUIA_REPORTE.md`: estructura mínima sugerida para el reporte.
- `tests/public/inputs/`: archivos de entrada públicos.
- `tests/public/expected/`: salidas exactas correspondientes.
- `tests/public/README.md`: descripción y uso de las pruebas.

## Importante

La base incluida no es una solución: reconoce únicamente `PLUS` y deja marcados los puntos que deben completarse. El material no contiene `Makefile` ni `CHANGELOG.md`.

Las pruebas públicas no sustituyen las pruebas que debe incluir cada equipo y no garantizan por sí solas la correctitud completa de la implementación.
